# DataShield-Databoard

Projet React minimal pour se familiariser avec Cursor et React.

## Branche `react-basis`

Setup minimal : React 19 + TypeScript + Vite.

### Démarrer

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:5173](http://localhost:5173) dans le navigateur.

### Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run preview` — prévisualiser le build
